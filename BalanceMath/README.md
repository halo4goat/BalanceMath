# BalanceMath

BalanceMath is an experimental calculator for a proposed binary operation:

**A ◇ B = A + B + |A - B| / gcd(A, B)**

Features:
- Calculate A ◇ B
- Compare A ◇ B with B ◇ A
- Test commutativity
- Test associativity with three numbers
- Automatically build a Windows EXE with GitHub Actions

This is an experiment. The formula is proposed for this project; that alone does not prove that equivalent mathematics has never appeared elsewhere.

After GitHub Actions finishes, download the **BalanceMath-Windows** artifact from the workflow run.
